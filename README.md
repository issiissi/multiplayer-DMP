# Multiplayer
This project is a multiplayer platformer game created as part of a university assignment. Players can move, jump, and interact within a shared game environment in real time. It demonstrates basic multiplayer mechanics, platformer physics, and networking concepts.

## Features
- 2D platformer gameplay (running, jumping, collision   detection)

- Multiplayer support using Godot's networking features

- Simple, responsive controls

- Basic UI for player status and game info

## Running locally 
### Exe:
- Download the WindowsExport from the release site 
- Extract it 
- Run Exe
### GodotProject:
- Download Godot version. 4.5 mono
- Start Godot 
- Clone repository 
- Import repository in Godot 
- Open Project 
- Run application
## Notes
- This project was created for educational purposes as part of a university task.

- Designed for local multiplayer testing; not optimized for online deployment.

- Controls: WASD to move, Space to jump
